# Volciclab-specific Unity scripts

An example project implementing this has moved to a [separate repository](https://github.com/ha5dzs/volciclab-programmable-scotoma), the core scripts are included here for reference. While most scripts can work stand-alone, there are some dependencies or some scripts have to be moved to specific GameObjects within a scene.

Each `.cs` file has its own sibling `.cs.md` documentation. Perhaps it's best to check [the Volciclab programmable scotoma](https://github.com/ha5dzs/volciclab-programmable-scotoma) Unity project to see how the entire thing is built up, rather than trying to study these scripts in isolation.
